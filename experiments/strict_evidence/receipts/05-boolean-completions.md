# Could Boolean evaluation alone recover another decision?

The blind baseline has 128 abstentions across all 134 assignments. For each executable individual rule we fixed every available operand to its observed value, preserved shared contract identities, and varied only missing operands. For scalar comparisons we tested thresholds and representatives on either side. For creatinine's interchangeable units we used a single reporting form. We passed the resulting values to the production evaluator, including the study applicability gate. A pair of different resulting dispositions is a counterexample to the claim that the existing bindings already determine one outcome. These are hypothetical contract values, never patient predictions.

Each of 106 individual executable abstentions admitted two distinct outcomes under its declared contracts. The remaining 22 stopped at a governing-text hold or a group-subject gate, including the group record whose protocol hold takes precedence. Independent review checked whether apparent alternatives in those texts could nevertheless settle the criterion on this note. None did. This exercise tests logical sufficiency of current bindings. The separate baseline audit checks for evidence lost before binding.

The stored [witnesses](05-boolean-completions.json) contain every case ID. The predictor and scorer never read this file. From the PocketMD directory, replay this diagnostic against the baseline prediction file with a fresh output path.
